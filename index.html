Krishi-Rakshak: farmer without vs. with the station

Concept simulator. Same crop, same rain, same water. Only the decisions differ.

Illustrative model, not measured data. Rainfall events, soil-water thresholds and the rain-signal reliability are assumptions to be validated in a pilot. Results show how the decision logic behaves, not field-proven savings.

Model: daily soil-water bucket, S(t+1) = S + 0.9×rain + irrigation − ET×stress factor, capped at 100 mm (excess drains). Yield proxy = actual ÷ potential evapotranspiration. "Without" = fixed 8-day routine, skips if it rained yesterday. "With" = irrigate only when station says square (≤50 mm); hold when a rain signal arrives and soil is not already dry. Station symbols: circle = fine, triangle = watch, square = irrigate now. Source and tests in this repository.
